# Findr Bot

Servidor base para la integración OAuth de Mercado Libre.

## Desarrollo

```bash
npm install
npm start
```

Endpoint OAuth:

`/oauth/callback`

## Próximos módulos

1. OAuth de Mercado Libre
2. Consulta de catálogo y publicaciones
3. Motor de oportunidades
4. Cálculo de precio máximo de compra
5. Alertas
6. Automatización controlada de compra
